# Aloria

Website project for Aloria, an online interior design studio.

## Design reference

The existing [Aloria Wix website](https://miagorbachev.wixsite.com/my-site-2) is the reference for the new site's visual language and animations.

Preserve its warm cream and taupe palette, elegant serif typography, spacious layouts, and large European-inspired interior photography. Review the live site's motion and interactions before implementing animations.

## Status

This repository is the starting point for the Aloria website rebuild. Website implementation has not started.
